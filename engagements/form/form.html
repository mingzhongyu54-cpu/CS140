The form tag has an "action" attribute. What does it do? The action button tells the browser where to send the data.

The form tag has a "method" attribute. What does it do? The method tag tells the browser how to send my data.

What is the difference between a "POST" and a "GET"? GET puts the inputted data directly into the URL. POST send the data through the requesst body. POST is more safer to use than GET.

How do you fill in a form control with a pre-set value, and how is that different from a placeholder?
Answer for each of these: text box, textarea, select box, checkbox, and radio button.

  1. Text Box: Use "value" for a preset value. Use "placeholder" for a hint.
  2. Text Area: Put preset text between the textarea tag. This allows a placeholder to go in the placeholder attribute.
  3. Select Box: Allows content to be seletced by default.
  4. Check Box: Add check to make something get selected by default.
  5. Radio Button: Radion button does not use placeholder, they identify and submit by giving a value to option seletced.
