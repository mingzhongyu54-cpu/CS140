Engagement Questions

  1. What kind of photos are good to encode using JPEG?

    2. Use JPEG when pictures have many hues of colors, and its very detailed.

  2. What kind of photos are good to encode using GIF?

    3. Use GIF when the pictures is less detailed and has a limited color palette, also GIF can be used for simple animations.

  3. What is unique about the PNG format?

    4. PNG supports image with transparency (good for icons and logos) and has limited lossless compression.

  4. How do you resize your photo to the size it should be displayed?

    5. Use photo editing software to resize and scale the image according to desired outcome is achieved.

  5. Why should you resize photos using photo editing software instead of resizing it using CSS?

    6. Resizing software reduces the size of the file, whereas resizing with CSS only changes the shape of the image.
