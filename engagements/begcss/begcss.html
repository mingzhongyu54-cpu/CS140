Questions

  1. Explain the difference between inline, embedded, and external CSS.

    2. Inline CSS is written directly to an HTML element by usingthe 'style' attribute. Embedded CSS is written within the 'style' tags in the 'HTML' document header. External CSS is written in a separate .css file and linked to the 'HTML' document using the 'link' tag.

  2. Explain why you should only use external CSS.

    3. Using external CSS allows for better organization, reusability, and maintainability of styles across multiple pages.

  3. What is a selector used for?

    4. Selector decides which HTML tag does the style apply to.
