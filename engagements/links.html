Absolute link is a complete URL that opens up a website on a different page, whereas relative link opens up a file/link on the same page. Use relative link over absolute link because it is more convenient and easier to control.

Rules of Relative Links

  1. Siblings - file name
  2. Child - folder name/file name
  3. Aunt/Uncle - ../links.html

Links in NAV tab should only open websites on the same page, it should not open an external website on a different page.
