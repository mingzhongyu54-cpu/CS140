Internet

Internet is a massive global network of connected computers and devices that share information with each other

Web

Web is a system of public webpages and digital documents connected by links. Accessed through the internet and a web browser.

How are the Internet and Web different?

Internet connects devices through infrastructure, whereas the Web provides the interface for accessing and sharing information.

ASCII and Unicode

ASCII is a 7 character encoding standard that supports up to 128 characters, whereas Unicode is a more universal and comprehensive encoding standard designed to support almost all languageswhile Unicode is a more comprehensive character encoding standard that supports characters from many languages and symbols.

What is UTF-8?

UTF-8 is a variable character length encoding standard used for representing Unicode characters in a computer systems.

URL

URL stands for Uniform Resource Locator, it is the term used to identify web addresses.

Domain Name

A unique identifier used to access websites through a web browser.

HTTP

HTTP stands for HyperText Transfer Protocol, used for transmitting web pages on the internet

HTTPS

HTTPS stands for HyperText Transfer Protocol Secure, unlike HTTP, it encrypts data for a secure connection between the web server and the client.

IP Address

An IP address, which stands for Internet Protocol address, is a unique numerical identifier assigned to each device connected to a network.

DNS

DNS stands for Domain Name System, it is a system that translates human-readable websites and numbers into computer-readable ones.

W3C Recommendation

W3C stands for World Wide Web Consortium, it is the standard specification for the web.

XML, XHTML, HTML, HTML5

XML (eXtensible Markup Language) is a general-purpose markup language that focuses on the purpose of the data, XHTML (eXtensible HyperText Markup Language) is a language focused on the presentation of data, HTML (HyperText Markup Language) is the standard language used to create web pages, HTML5 is the modern standard language for creating web pages.
